- FACTSPORT_MATCHES_BACKEND=postgres: base matches read model only (migration 0001); base match projection intentionally does not select season.

- FACTSPORT_HOMEPAGE_BACKEND=postgres: featured matches/homepage setting views; requires migration 0006.

- FACTSPORT_COMPETITIONS_BACKEND=postgres: standings, same-season form and player leaders; requires migrations 0006-0007.
