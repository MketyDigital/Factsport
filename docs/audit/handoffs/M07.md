## 3. Changes on the v2 branch

### Score integrity and provider precedence
- Added `lib/football-data-score.cjs` and tests. Unknown, partial, negative or non-integer full-time scores are not converted into synthetic 0–0. Numeric ESPN score strings are parsed without treating blanks as zero.
- Updated `app/api/sync-fd/route.ts` to preserve existing scores and not mark a fixture FT until both verified full-time scores exist.
- Updated `scripts/sync-gh.js` so the scheduled fixture importer preserves unknown scores, does not overwrite ESPN-owned live status, and only applies football-data scores to ESPN-linked rows for verified FT results.
- Updated `scripts/fetch-espn-cups.js` to avoid false 0–0 writes, preserve already-settled results, and fail closed if its existing-match lookup fails.
- Converted the five legacy automation scripts from CommonJS `require` to ESM imports to match the v2 branch's `type: module`; added syntax regression tests and CI validation.

### Monthly prize qualification
- Added `lib/prize-qualification.cjs` with a shared exact-score and champion-criteria evaluator. Exact scores are determined by comparison with a verified terminal match result, not the inconsistent `points_awarded === 10` assumption.
- Added `app/lib/admin/monthly-prize-audit.ts`, used by both the scheduled API route and admin server action. It applies the configured exact-score target and points floor, checks the documented weekly activity, distinct-league, home/away/draw and score-variety rules, pages through VIP candidates, ranks only fully qualified candidates, and uses a deterministic UUID tie-break after points.
- Standardized the prize sequence at $500 / $300 / $200 and the audit period to the previous completed UTC month.
- Updated the admin report label to display the configured league threshold.
- Updated the monthly reset route to reset both standard monthly counters and prize-eligible monthly counters in the same database update.

### Staging diagnostics
- Updated the protected app-staging workflow to emit only sanitized SQLSTATE/error-class diagnostics if compound-cursor pagination fails. No SQL text, connection string or secret is logged.
